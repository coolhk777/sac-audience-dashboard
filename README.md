# 예술의전당 공연·전시 입장객 현황 대시보드

예술의전당 공연·전시 입장객 데이터(2011~2025년, 51,938건)를 브라우저에서 바로 분석하는 단일 HTML 대시보드입니다.

## 사용법

- `예술의전당_입장객_대시보드.html`을 더블클릭하면 바로 열립니다. 서버나 설치가 필요 없습니다.
- 엑셀(xlsx)·CSV 파일을 끌어다 놓으면 그 데이터로 교체해 분석합니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 주요 기능

- 연도·분야(공연/전시)·장소·구분(기획/대관) 필터 (AND 조건)
- KPI: 총 입장객, 회차(행) 수, 회차당 평균 입장객, 유료 관객 비율, 입장객 최다 장소
- 차트: 연도별 추이, 장소별 비교, 월별·요일별 패턴, 공연 시간대별 입장객, 공연·전시명 TOP 10
- 상세 데이터: 검색, 정렬, 20/50/100행 페이징
- PDF 저장 (A4 세로, 요약 화면만 출력)

## 폴더 구조

```
├── 예술의전당_입장객_대시보드.html   # 빌드 결과물 (직접 수정하지 말 것)
├── index.html                       # 웹 배포 시 첫 화면 → 대시보드로 이동
├── src/
│   ├── dashboard.template.html      # HTML·CSS·JS 본체
│   ├── build_data.ps1               # 분석용 데이터 TSV → data.json
│   ├── data.json                    # 내장용 기본 데이터
│   └── build.ps1                    # 템플릿 + data.json → 최종 HTML
└── docs/
    └── 데이터_분석_KPI_제안.md       # 컬럼 분류·KPI·분석 질문·데이터 유의사항
```

## 빌드

코드는 `src/dashboard.template.html`에서 수정한 뒤 PowerShell에서 다시 빌드합니다.

```powershell
.\src\build.ps1
```

## 데이터 유의사항

- 전시 데이터는 2023년부터만 있습니다.
- 2011~2022년 ‘공연’ 분류에는 미술관·박물관 전시가 섞여 있습니다. 자세한 내용은 `docs/데이터_분석_KPI_제안.md`를 참고하세요.
- 원본 엑셀 파일은 저장소에 포함하지 않았습니다.
